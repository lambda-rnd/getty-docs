# Synthetic examples

**Status:** Preview · **Audience:** Integrators and contributors

These examples contain no production identifiers or user data.

- [Poll result](poll-result.example.json)
- [Raffle result](raffle-result.example.json)

The poll and raffle files illustrate final permanent result records, not full AO state. Poll option IDs follow the schema's string representation; they are not numeric array positions. For the relationship between result records and versioned projections, see [Publication and verification](../docs/publication-and-verification.md).

When contributing an example, replace every host, wallet, token, process ID, transaction ID, username, and channel name with an obviously fictional value.
