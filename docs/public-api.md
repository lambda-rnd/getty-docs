# Supported public API

**Status:** Preview · **Audience:** Integrators and developers

This page lists public integration surfaces that are useful to viewers, streamers, and overlay consumers. Administrative and internal routes are intentionally omitted.

Use the base URL supplied by the getty deployment:

```text
https://<getty-host>
```

## Widgets

Common public widget entry points include:

```text
/widgets/announcement
/widgets/chat
/widgets/giveaway
/widgets/polls
/widgets/achievements
/widgets/events
/widgets/liveviews
/widgets/tip-goal
/widgets/tip-notification
```

Widget availability varies by deployment. Tokenized widget URLs must be generated by getty admin and should not be copied into public bug reports.

## Read-only endpoints

| Method | Path            | Purpose                                    |
| ------ | --------------- | ------------------------------------------ |
| `GET`  | `/api/ar-price` | Current AR/USD reference used by getty     |
| `GET`  | `/obs/widgets`  | Widget URLs and recommended OBS dimensions |

Some public module state requires a getty-issued read token. This documentation does not guarantee undocumented query parameters or response fields.

## Compatibility

- Clients must tolerate additive response fields.
- Preview contracts can change before being marked stable.
- Rate limits and abuse controls may apply.
- Public read access does not authorize writes.
