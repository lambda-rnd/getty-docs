# Security Policy

## Reporting a vulnerability

Do not open public issues containing vulnerability details, credentials, private user data, production identifiers, or reproduction steps against live infrastructure.

Report security issues privately to `hello@getty.sh`. Include the affected public contract, the minimum safe reproduction information, and the potential impact. Do not probe production accounts, shared infrastructure, or other users' data.

## Documentation leaks

If public documentation exposes a secret or private identifier, report the exact file and revision privately. Do not quote the exposed value in a public issue.
